# CU-009 - Cálculo de indicadores financieros

## Información general

**Identificador:** CU-009

**Actor principal:** ACT-002 - Analista financiero

## Objetivo

Calcular indicadores financieros que permitan analizar la rentabilidad y conveniencia económica de una cartera.


## Precondiciones

- Deben existir flujos financieros proyectados.
- Debe existir información suficiente para calcular los indicadores solicitados.

## Flujo principal

1. El analista financiero selecciona una valoración.
2. El sistema recupera los flujos proyectados y parámetros financieros.
3. El sistema calcula el VPN.
4. El sistema calcula la TIR cuando los flujos lo permiten.
5. El sistema calcula el ROI.
6. El sistema registra los indicadores obtenidos.
7. El sistema presenta los resultados al analista.

## Flujos alternativos

- Si no es posible calcular la TIR, el sistema informa la condición.
- Si faltan flujos o parámetros, el sistema no calcula el indicador afectado.
- Si existen escenarios alternativos, el sistema calcula los indicadores por escenario.

## Postcondiciones

- Los indicadores financieros calculados quedan asociados a la valoración correspondiente.
