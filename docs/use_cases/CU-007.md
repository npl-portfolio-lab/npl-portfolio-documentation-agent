# CU-007 - Predicción de recuperación

## Información general

**Identificador:** CU-007

**Actor principal:** ACT-001 - Analista de riesgo

## Objetivo

Estimar la probabilidad de recuperación asociada a cada obligación utilizando un modelo previamente evaluado y aprobado.


## Precondiciones

- Debe existir un modelo aprobado para predicción.
- Las obligaciones deben contar con las variables requeridas por el modelo.

## Flujo principal

1. El sistema recibe las obligaciones que serán evaluadas.
2. El sistema recupera el modelo aprobado.
3. El sistema valida las variables requeridas por el modelo.
4. El sistema genera la probabilidad de recuperación para cada obligación.
5. El sistema valida que las probabilidades estén dentro del rango permitido.
6. El sistema registra el modelo y versión utilizados.
7. El sistema almacena los resultados de predicción.

## Flujos alternativos

- Si una obligación no contiene las variables mínimas, el sistema la marca como no evaluable.
- Si no existe un modelo aprobado, el sistema no genera predicciones.
- Si una probabilidad se encuentra fuera del rango válido, el resultado es rechazado.

## Postcondiciones

- Las obligaciones evaluables cuentan con una probabilidad de recuperación registrada.
