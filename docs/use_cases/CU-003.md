# CU-003 - Transformación de datos

## Información general

**Identificador:** CU-003

**Actor principal:** ACT-001 - Analista de riesgo

## Objetivo

Limpiar, normalizar y transformar los datos previamente validados para dejarlos listos para análisis, modelado y valoración.


## Precondiciones

- Debe existir un conjunto de datos validado.
- Las incidencias críticas de calidad deben haber sido tratadas.

## Flujo principal

1. El sistema recibe el conjunto de datos validado.
2. El sistema estandariza nombres y tipos de datos.
3. El sistema transforma formatos de fechas.
4. El sistema aplica reglas para tratamiento de valores faltantes.
5. El sistema normaliza variables requeridas.
6. El sistema genera el conjunto de datos procesado.
7. El sistema registra las transformaciones aplicadas.

## Flujos alternativos

- Si una transformación no puede aplicarse, el sistema registra la incidencia.
- Si un registro incumple reglas críticas, el sistema lo separa para revisión.

## Postcondiciones

- Existe un conjunto de datos transformado y disponible para persistencia o análisis.
