# CU-010 - Consulta de resultados

## Información general

**Identificador:** CU-010

**Actor principal:** ACT-001 - Analista de riesgo

## Objetivo

Permitir consultar los resultados generados por los procesos de predicción, evaluación de modelos y valoración financiera.


## Precondiciones

- Deben existir resultados previamente generados y almacenados.

## Flujo principal

1. El usuario accede al módulo de consulta.
2. El usuario define los filtros de búsqueda.
3. El sistema recupera los resultados disponibles.
4. El sistema presenta las predicciones y resultados asociados.
5. El sistema muestra las referencias de modelo cuando corresponda.
6. El sistema muestra la información de valoración financiera disponible.
7. El usuario consulta el detalle del resultado seleccionado.

## Flujos alternativos

- Si no existen resultados para los filtros seleccionados, el sistema informa que no se encontraron datos.
- Si un resultado no tiene valoración asociada, el sistema presenta únicamente la información disponible.

## Postcondiciones

- El usuario ha podido consultar los resultados disponibles sin modificar la información almacenada.
