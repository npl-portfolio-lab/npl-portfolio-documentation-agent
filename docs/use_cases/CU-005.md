# CU-005 - Entrenamiento de modelos

## Información general

**Identificador:** CU-005

**Actor principal:** ACT-001 - Analista de riesgo

## Objetivo

Entrenar modelos de Machine Learning utilizando información histórica preparada para estimar probabilidades de recuperación.


## Precondiciones

- Debe existir un dataset preparado para modelado.
- Las variables objetivo y predictoras deben estar definidas.
- Los datos deben permitir separar entrenamiento y evaluación.

## Flujo principal

1. El analista selecciona el dataset de entrenamiento.
2. El sistema prepara las variables predictoras y la variable objetivo.
3. El sistema divide los datos para entrenamiento y evaluación.
4. El sistema entrena los modelos configurados.
5. El sistema registra parámetros y versiones de los modelos.
6. El sistema calcula las métricas iniciales.
7. El sistema almacena los resultados del entrenamiento.

## Flujos alternativos

- Si el dataset no cumple las condiciones mínimas, el sistema bloquea el entrenamiento.
- Si un modelo falla durante el entrenamiento, el sistema registra el error y continúa con los modelos restantes cuando sea posible.

## Postcondiciones

- Existen modelos entrenados disponibles para evaluación y comparación.
