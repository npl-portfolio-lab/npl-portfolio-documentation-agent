# CU-002 - Validación de calidad de datos

## Información general

**Identificador:** CU-002

**Actor principal:** ACT-001 - Analista de riesgo

## Objetivo

Verificar que los datos cargados cumplan con las condiciones mínimas de calidad necesarias para continuar el procesamiento.


## Precondiciones

- Debe existir un conjunto de datos previamente cargado.

## Flujo principal

1. El sistema recibe el conjunto de datos cargado.
2. El sistema valida la estructura de columnas.
3. El sistema verifica campos obligatorios.
4. El sistema identifica registros duplicados.
5. El sistema identifica valores nulos.
6. El sistema detecta formatos y valores inconsistentes.
7. El sistema genera un resumen de calidad de datos.
8. El sistema determina si los datos pueden continuar al proceso de transformación.

## Flujos alternativos

- Si faltan campos obligatorios, el sistema rechaza el conjunto de datos.
- Si existen duplicados, el sistema registra los registros identificados.
- Si existen inconsistencias, el sistema registra las observaciones para tratamiento.

## Postcondiciones

- El conjunto de datos queda clasificado como válido o con incidencias de calidad.
