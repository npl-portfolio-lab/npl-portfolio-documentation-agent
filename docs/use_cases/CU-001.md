# CU-001 - Carga de datos históricos

## Información general

**Identificador:** CU-001

**Actor principal:** ACT-001 - Analista de riesgo

## Objetivo

Permitir incorporar información histórica de créditos para su posterior validación, transformación y análisis.


## Precondiciones

- El usuario debe tener acceso autorizado al sistema.
- El archivo o fuente de datos debe estar disponible.

## Flujo principal

1. El usuario selecciona la fuente de datos histórica.
2. El sistema recibe el archivo o conjunto de datos.
3. El sistema verifica que el archivo pueda ser leído.
4. El sistema identifica las columnas disponibles.
5. El sistema registra la carga recibida.
6. El sistema deja los datos disponibles para validación de calidad.

## Flujos alternativos

- Si el archivo no puede ser leído, el sistema rechaza la carga.
- Si el formato no es compatible, el sistema informa el error al usuario.

## Postcondiciones

- Los datos históricos quedan disponibles para el proceso de validación.
