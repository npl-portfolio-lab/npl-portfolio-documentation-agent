# CU-004 - Persistencia de información

## Información general

**Identificador:** CU-004

**Actor principal:** ACT-003 - Administrador

## Objetivo

Almacenar de forma controlada la información procesada garantizando consistencia, trazabilidad y disponibilidad.


## Precondiciones

- Debe existir un conjunto de datos procesado.
- Los datos deben haber superado las validaciones definidas.

## Flujo principal

1. El sistema recibe el conjunto de datos procesado.
2. El sistema verifica que la información sea apta para persistencia.
3. El sistema prepara los registros para almacenamiento.
4. El sistema almacena la información en la base de datos.
5. El sistema registra el resultado de la operación.
6. El sistema deja la información disponible para procesos posteriores.

## Flujos alternativos

- Si ocurre un error de persistencia, el sistema revierte la operación cuando corresponda.
- Si existen registros inválidos, el sistema evita su persistencia como datos procesados.

## Postcondiciones

- La información válida queda almacenada y disponible para consulta.
