# CU-006 - Comparación de modelos

## Información general

**Identificador:** CU-006

**Actor principal:** ACT-001 - Analista de riesgo

## Objetivo

Comparar el desempeño de los modelos entrenados mediante métricas definidas para seleccionar el modelo más adecuado.


## Precondiciones

- Deben existir dos o más modelos entrenados o al menos un modelo candidato evaluable.
- Debe existir un conjunto de evaluación independiente.

## Flujo principal

1. El sistema recupera los modelos candidatos.
2. El sistema ejecuta la evaluación sobre los datos definidos.
3. El sistema calcula las métricas de cada modelo.
4. El sistema compara los resultados obtenidos.
5. El sistema identifica el modelo con mejor desempeño según los criterios establecidos.
6. El sistema registra la comparación y las métricas.

## Flujos alternativos

- Si ningún modelo cumple los criterios mínimos, el sistema no aprueba un modelo para predicción.
- Si faltan métricas necesarias, el sistema marca la comparación como incompleta.

## Postcondiciones

- Existe un resultado de comparación de modelos.
- Puede existir un modelo seleccionado para predicción.
