# CU-008 - Valoración de cartera

## Información general

**Identificador:** CU-008

**Actor principal:** ACT-002 - Analista financiero

## Objetivo

Estimar el valor económico de una cartera utilizando las recuperaciones esperadas, los costos y los supuestos financieros definidos.


## Precondiciones

- Debe existir una cartera identificada.
- Deben existir estimaciones de recuperación o información suficiente para proyectarlas.
- Debe existir una tasa de descuento definida para el escenario.

## Flujo principal

1. El analista financiero selecciona la cartera a valorar.
2. El sistema recupera las probabilidades y estimaciones de recuperación.
3. El sistema proyecta los flujos de recuperación.
4. El sistema incorpora los costos de recuperación disponibles.
5. El sistema aplica la tasa de descuento definida.
6. El sistema calcula el valor económico estimado de la cartera.
7. El sistema registra los supuestos y resultados de valoración.

## Flujos alternativos

- Si no existe información suficiente para proyectar recuperaciones, el sistema marca la valoración como incompleta.
- Si no existe una tasa de descuento válida, el sistema no calcula el valor presente.
- Si se selecciona un escenario alternativo, el sistema aplica los parámetros correspondientes.

## Postcondiciones

- Existe una valoración financiera registrada para la cartera y escenario analizados.
